# Журнал смены

Раздел «Операции → Журнал смены» заменяет отдельную программу «Журнал инженеров по АСУ»
(PyQt5 + PostgreSQL). Вход — по учётным записям склада, отдельное подключение к базе не нужно.

## Правила (как в старой программе)

- 1-я смена — с 08:30 до 20:30, 2-я — с 20:30 до 08:30. Записи после полуночи относятся
  ко 2-й смене предыдущего дня и в таблице идут в конце смены.
- Добавлять, изменять и удалять записи, а также менять состав инженеров можно только
  в текущей смене. Прошлые смены — только просмотр. Будущие даты не открываются.
- Проверки выполняются на сервере, по часам сервера.
- Писать в журнал могут роли `admin`, `editor`, `maintenance`; `reader` только смотрит.
  Все изменения попадают в журнал операций.

## Инженеры на смене

Выбираются из пользователей склада (ФИО из профиля). Если у инженера нет учётной записи,
ФИО можно вписать вручную.

## Письмо и Word

- **Письмо в Outlook** — скачивается файл письма (.eml) с той же таблицей, что вставляла
  старая программа: тема «Сводка - 1-я смена от ДД-ММ-ГГГГ», адресаты из настроек.
  Outlook открывает его как новое письмо, остаётся нажать «Отправить». Чтобы файл открывался
  сразу, в загрузках браузера выберите «Всегда открывать файлы этого типа».
- **Скопировать таблицу для письма** — запасной вариант: таблица копируется, её можно
  вставить в любое письмо (Ctrl+V).
- **Скачать в Word** — .docx с инженерами и записями смены.
- Адресаты письма (Кому / Копия) меняет администратор: кнопка «Адресаты письма» на странице журнала.

## Перенос старых данных

Один раз, после обновления склада. Повторный запуск безопасен: уже перенесённые записи пропускаются.
Сначала можно проверить с `--dry-run` (ничего не записывает).

Напрямую из PostgreSQL (нужен `pip install psycopg2-binary`, сервер склада должен видеть Postgres):

```bash
flask import-journal --pg "host=АДРЕС dbname=shift_journal_db user=ЛОГИН password=ПАРОЛЬ" --dry-run
flask import-journal --pg "host=АДРЕС dbname=shift_journal_db user=ЛОГИН password=ПАРОЛЬ"
```

Или через CSV: в pgAdmin выгрузите таблицы `journal`, `engineers`, `engineers_info`
(правый клик → Import/Export → Export, с заголовками, кодировка UTF8) в одну папку под именами
`journal.csv`, `engineers.csv`, `engineers_info.csv`, затем:

```bash
flask import-journal --csv-dir ПАПКА
```

Что переносится: все записи журнала и составы смен. Табельные номера из справочника инженеров
записываются в профили пользователей склада с тем же ФИО (если номер в профиле ещё пустой);
команда выведет список инженеров, для которых пользователь не нашёлся.

Голосовой ввод не перенесён.
