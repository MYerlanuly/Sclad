# Развёртывание в корпоративной сети без доступа в интернет

## 1. Подготовка на компьютере с интернетом

### 1.1 Скачать JS-библиотеки для офлайн-работы

Из корня проекта выполните один раз:

```bash
python scripts/download_offline_assets.py
```

Скрипт создаст папку `static/js/` и скачает в неё Tailwind CSS и Chart.js. Без этих файлов на сервере не будут подгружаться стили и график ТО.

### 1.2 (Опционально) Подготовить пакеты Python для установки без интернета

Если на сервере нет доступа к PyPI, соберите колеса (wheels) на машине с интернетом:

```bash
pip download -r requirements.txt -d wheels
```

Скопируйте папку `wheels/` на сервер вместе с проектом.

---

## 2. Копирование на сервер

Перенесите на сервер в корпоративной сети:

- всю папку проекта (включая `static/js/` с скачанными файлами);
- при необходимости — папку `wheels/`.

---

## 3. Установка и запуск на сервере

### 3.1 Python 3.8+

Убедитесь, что на сервере установлен Python 3.8 или новее.

### 3.2 Зависимости

**Если на сервере есть доступ в интернет (например, внутренний PyPI):**

```bash
pip install -r requirements.txt
```

**Если интернета нет** (установка из подготовленных колес):

```bash
pip install --no-index --find-links wheels -r requirements.txt
```

### 3.3 Переменные окружения

Создайте файл `.env` в корне проекта (по образцу `.env.example`):

- `FLASK_SECRET_KEY` — секретный ключ для сессий (придумайте длинную случайную строку).
- При необходимости укажите путь к БД и другие настройки.

### 3.4 Создание БД и пользователя (при первом запуске)

```bash
# Создать БД из schema.sql и выполнить миграции
python -m flask init-db

# Создать пользователя для входа
python -m flask create-user -u admin -p "ваш_надёжный_пароль"
```

### 3.5 Запуск

**Для проверки (встроенный сервер):**

```bash
python app.py
```

Приложение будет доступно по адресу `http://IP_СЕРВЕРА:5000`.

**Для постоянной работы (рекомендуется)** используйте production-сервер, например **Waitress** (работает под Windows и не требует интернета):

```bash
pip install waitress
waitress-serve --host=0.0.0.0 --port=5000 app:app
```

Или **Gunicorn** (Linux):

```bash
pip install gunicorn
gunicorn -w 2 -b 0.0.0.0:5000 "app:create_app()"
```

Добавьте `waitress` или `gunicorn` в `requirements.txt` и при подготовке офлайн-установки снова выполните `pip download -r requirements.txt -d wheels`.

---

## 4. Доступ из сети

Пользователи открывают в браузере адрес вида `http://IP_СЕРВЕРА:5000` или `http://имя-сервера:5000`. Убедитесь, что порт 5000 не блокируется файрволом и что к нему разрешён доступ с рабочих мест.

---

## 5. Резервное копирование БД

Файл базы данных — `inventory.db` в корне проекта. Регулярно копируйте его в безопасное место (в интерфейсе есть кнопка «Резервная копия БД» в настройках и на странице списков).
