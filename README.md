### Инвентаризация оборудования, техники, SIM-карт и датчиков

Веб-приложение на **Flask + SQLite** для учёта оборудования, техники, SIM-карт и датчиков, а также их установки на технику.

#### Установка зависимостей

В корне проекта (`Sclad`) выполните:

```bash
pip install flask
```

При необходимости можно создать виртуальное окружение:

```bash
python -m venv .venv
.venv\Scripts\activate
pip install flask
```

#### Инициализация базы данных

Вариант 1 — автоматическая

- При первом запуске `python app.py` будет создан файл `inventory.db` и выполнен скрипт `schema.sql` с созданием таблиц и тестовых данных.

Вариант 2 — через Flask CLI

```bash
set FLASK_APP=app:create_app
flask init-db
```

После этого в каталоге появится `inventory.db` с заполненными справочниками и примерами данных.

#### Запуск приложения

```bash
python app.py
```

По умолчанию сервер будет доступен по адресу `http://127.0.0.1:5000/`.

#### Основные разделы интерфейса

- **Оборудование**: CRUD по оборудованию, фильтрация по статусу, карточка оборудования, история установок и операций.
- **Техника**: типы, модели, список техники, карточка машины с установленными SIM-картами, датчиками и оборудованием.
- **SIM-карты**: CRUD, фильтрация по статусу, история установок и операций.
- **Датчики**: CRUD, фильтрация по статусу, позиции датчиков, история установок и операций.
- **Журнал операций**: просмотр операций (установка, демонтаж, смена статусов) с фильтрацией по сущности и типу операции.
