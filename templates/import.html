Массовый ввод техники, оборудования и SIM-карт

Вместо ввода по одной записи можно загрузить CSV-файл. Скачайте шаблон, заполните его в Excel или другом редакторе (разделитель столбцов — точка с запятой, кодировка UTF-8), затем загрузите файл. Дубликаты и строки с ошибками будут пропущены, в конце покажется отчёт.

Импорт техники
Скачать шаблон CSV

Колонки: Инв. номер; Модель. Название модели должно точно совпадать с одной из моделей в справочнике (Техника → Модели техники).

Импорт оборудования
Скачать шаблон CSV

Колонки: Наименование; Серийный номер; Описание (необязательно); Статус (например «На складе»); Вид — «Датчик» или «Прочее» (если пусто — прочее). Для датчиков при установке на технику нужно будет указать позицию (колесо и т.д.).

Импорт SIM-карт
Скачать шаблон CSV

Колонки: Номер; ICCID; IP (необязательно); Оператор; Описание; Тариф; Статус (например «На складе», по умолчанию — «На складе»). ICCID должен быть уникальным.

Порядок действий
  1. Убедитесь, что в справочниках есть нужные типы и модели техники (если импортируете технику) — их по-прежнему добавляют вручную в разделе «Техника».
  2. Скачайте шаблон CSV для техники, оборудования или SIM-карт.
  3. Заполните таблицу: первая строка может быть заголовком. Для SIM-карт: Номер; ICCID; IP; Оператор; Описание; Тариф; Статус. Сохраните в формате CSV (разделитель — точка с запятой), кодировка UTF-8.
  4. На этой странице выберите файл и нажмите «Загрузить и импортировать». Появится сообщение: сколько записей добавлено и сколько пропущено (с кратким описанием ошибок).
